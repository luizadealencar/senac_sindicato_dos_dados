    IV

    Quadro de filiados

    Quem assinou o contrato do Sindicato. Cada ficha entra aqui por pull request — o mesmo fluxo que você vai usar em qualquer equipe.

    Filie-se ao Sindicato

    Entre com sua conta do GitHub e preencha a ficha. É o mesmo login que você usa para versionar código — o avatar e o nome vêm do seu perfil, sem precisar enviar foto.

    Filiar-se pelo GitHub

    Combinem o nome do time antes e escrevam igual: quem usa o mesmo nome cai na mesma célula do placar. O XP quem lança sou eu, conforme as missões chegam.

    Prefere pelo código? Abra aqui o passo a passo do pull request
    1. Faça um fork do repositório.
    2. No index.html, procure por alunos: e acrescente o seu bloco:
    {nome:"Seu Nome Completo", github:"seu-usuario", celula:"Nome do seu time"}

    Commit numa branch nova, abra o pull request, e assim que eu aprovar sua ficha aparece.
